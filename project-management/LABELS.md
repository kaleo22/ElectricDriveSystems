# Recommended GitHub Labels

Use this list when creating labels in the repository.
See [`SETUP_GITHUB.md`](../SETUP_GITHUB.md) for the `gh` CLI commands to create them.

---

## Type Labels

| Name | Color | Description |
|------|-------|-------------|
| `type: feature` | `#0075ca` | New feature or work package |
| `type: bug` | `#d73a4a` | Something is not working |
| `type: task` | `#e4e669` | General task or chore |
| `type: docs` | `#0075ca` | Documentation changes |
| `type: refactor` | `#cfd3d7` | Code restructuring (no behaviour change) |
| `type: test` | `#0e8a16` | Test additions or updates |

## Status Labels

| Name | Color | Description |
|------|-------|-------------|
| `status: in-progress` | `#fbca04` | Work is actively underway |
| `status: blocked` | `#b60205` | Blocked by another issue or external factor |
| `status: needs-review` | `#d93f0b` | Awaiting review |
| `status: on-hold` | `#cfd3d7` | Paused, pending decision |

## Priority Labels

| Name | Color | Description |
|------|-------|-------------|
| `priority: high` | `#b60205` | High priority |
| `priority: medium` | `#fbca04` | Medium priority |
| `priority: low` | `#0e8a16` | Low priority |
