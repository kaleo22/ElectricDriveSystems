# Meeting Notes

This folder contains meeting notes for all team meetings.

## Naming Convention

```text
YYYY-MM-DD-<meeting-type>.md
```

Examples:

- `2024-10-07-kickoff.md`
- `2024-10-14-weekly.md`
- `2024-11-01-design-review.md`

## Template

Use the following structure for each meeting note:

---

- **Date:** YYYY-MM-DD
- **Attendees:** [list names]
- **Facilitator:** [name]
- **Note-taker:** [name]
