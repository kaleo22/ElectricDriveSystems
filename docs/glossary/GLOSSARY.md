# Project Glossary

This file defines terms, abbreviations, and acronyms used across all project documentation and code.
Keep it updated as new terms are introduced.

---

| Term / Abbreviation | Full Form | Definition |
|---------------------|-----------|------------|
| ADR | Architecture Decision Record | A document capturing a significant design decision and its rationale. |
| BDC | Brushed DC (motor) | A type of electric motor that uses brushes for commutation. |
| EMF | Electromotive Force | Voltage generated by the spinning motor (back-EMF). |
| FET / MOSFET | Metal-Oxide-Semiconductor Field-Effect Transistor | Switching element used in the power stage. |
| H-bridge | — | A circuit topology that allows a DC motor to be driven in both directions. |
| MCU | Microcontroller Unit | The embedded processor used on the control board. |
| PCB | Printed Circuit Board | The physical board on which electronic components are mounted. |
| PWM | Pulse-Width Modulation | Technique used to control motor speed by varying duty cycle. |
| PR | Pull Request | A GitHub mechanism to propose and review code/document changes. |
| RPM | Revolutions Per Minute | Unit of rotational speed. |

_Add new terms alphabetically._
