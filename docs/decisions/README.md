# Architecture Decision Records (ADRs)

This folder contains Architecture Decision Records for the Electric Drive Systems project.

An ADR documents a significant technical or architectural decision, its context, the chosen approach, and the reasons why alternatives were rejected.

## How to Create an ADR

1. Copy `ADR-0001-template.md` and rename it to the next sequential number:
   ```
   ADR-0002-<short-title>.md
   ```
2. Fill in all sections.
3. Set the status to `Proposed` initially.
4. Open a PR — the ADR is accepted when the PR is merged.
